# 🥛 متجر أبو يوسف للألبان (Abo Yosef Dairy)

تطبيق ويب متقدم (PWA) مخصص للهواتف المحمولة لإدارة معدلات إنتاج وتوريد الألبان وحسابات الموردين اليومية والأسبوعية.

---

## ✨ المميزات الرئيسية والتحديثات الشاملة (360°):

### 1. 📅 دورة الحساب الأسبوعي (من الأربعاء إلى الأربعاء)
- تبدأ دورة الأسبوع رسمياً كل يوم **أربعاء** وتنتهي يوم **الأربعاء** التالي.
- يوم الأربعاء هو يوم تسليم الفلوس لجميع العملاء وتصفية حساب الأسبوع بالكامل.
- ظهور شارة وتنبيه تلقائي كل يوم أربعاء لتسليم المستحقات ومتابعة كشف الحساب.
- ميزة إغلاق الأسبوع وأرشفته في السجل التاريخي وبدء أسبوع جديد بضغطة زر.

### 2. 🔢 خانات إدخال فارغة وسريعة (بدون أصفار مزعجة)
- تظهر خانات إدخال كميات اللبن اليومية فارغة تماماً دون أي أصفار مسبقة (`0`) لسرعة وسلاسة الكتابة على لوحة مفاتيح الهاتف دون الحاجة لمسح الصفر.

### 3. 🥛 أزرار الكسور باللغة العربية
- استبدال الرموز الرياضية المعقدة بأزرار عربية صريحة ومريحة:
  - **+ ربع** (+0.25 كجم)
  - **+ نص** (+0.50 كجم)
  - **+ تلات أرباع** (+0.75 كجم)
  - **+ كيلو** (+1.00 كجم)
  - **مسح ✕**
- عرض الكميات باللغة العربية الدارجة (مثال: "5 ونصف كجم"، "ربع كجم").

### 4. 👥 إضافة عملاء متعددين دفعة واحدة (Bulk Add)
- **قائمة أسماء سريعة**: كتابة أسماء العملاء تحت بعض (سطر لكل عميل) مع تحديد أسعار موحدة للبقر والجاموس بضغطة زر واحدة، ويتم إنشاء كل عميل كحساب مستقل فوراً.
- **جدول أسطر تفاعلي**: إضافة صفوف متعددة وتخصيص أسعار كل عميل على حدة وحفظ الكل معاً.

### 5. 📱 تصميم عصري مخصص للموبايل (Mobile-First UI/UX)
- خط عربي فخم وعصري (**Cairo**) مع أعلى درجات الوضوح والتباين.
- شريط تنقل سفلي مرن ومتجاوب (Bottom Navigation Bar).
- تدرجات لونية هادئة تعبر عن هوية الألبان (أزرق نيلي، أخضر مالي، أبيض كريمي).
- بطاقات وإحصائيات تفاعلية فورية.

### 6. 💬 مشاركة كشف الحساب عبر واتساب (WhatsApp Share)
- إرسال فاتورة تفصيلية منسقة بضغطة زر إلى رقم العميل توضح كميات البقر والجاموس والمبلغ الإجمالي المستحق له.
- مشاركة تقرير عام وشامل للأسبوع.

### 7. 📊 تصدير Excel / CSV وطباعة فواتير
- تصدير كشف حساب الأسبوع إلى ملف Excel بنقرة واحدة.
- طباعة نظيفة ومنسقة مناسبة للطابعات الحرارية أو مقاس A4.

### 8. 💾 حفظ تلقائي ونسخ احتياطي كامل (Offline & Backup)
- حفظ فوري للبيانات عبر IndexedDB المحلي، يعمل 100% بدون اتصال بالإنترنت.
- تصدير واسترجاع نسخة احتياطية من ملف JSON في أي وقت لحماية البيانات ونقلها لأي هاتف آخر.
- تثبيت مباشر على الشاشة الرئيسية للهاتف كتطبيق أصلي (Progressive Web App).

---

## 🚀 طريقة الاستخدام:
1. افتح ملف `index.html` في أي متصفح (على الهاتف أو الكمبيوتر).
2. يمكنك تثبيته عبر خيار "إضافة إلى الشاشة الرئيسية" (Add to Home Screen) ليعمل مثل تطبيق الموبايل تماماً.
3. التعديلات والبيانات تُحفظ محلياً على جهازك تلقائياً وبأمان.
