# 🥛 متجر أبو يوسف للألبان (Abo Yosef Dairy)

تطبيق متطور ومخصص للهواتف المحمولة لإدارة توريد الألبان اليومية وحسابات الزباين الأسبوعية.

---

## 📅 دورة العمل الأسبوعية (من الخميس إلى الأربعاء):
- **أيام التوريد اليومي**:
  1. **الخميس**
  2. **الجمعة**
  3. **السبت**
  4. **الأحد**
  5. **الاثنين**
  6. **الثلاثاء**
  7. **الأربعاء (يوم القبض)**
- **يوم القبض والتصفية (الأربعاء)**:
  - هو اليوم المحدد لحساب الأسبوع بالكامل وتسليم الفلوس لجميع الزباين.
  - حساب إجمالي كل الزباين مع بعض (إجمالي البقر، الجاموس، والمبلغ الإجمالي المطلوب بالجنيه).
  - حساب كل زبون لوحده بالتفصيل (ما ورّده في كل يوم، أسعار الكيلو، والمبلغ المستحق له).
  - إمكانية التنقل والتعديل على أي يوم من أيام الأسبوع في أي وقت بسهولة وبدون أي قيود.

---

## ⚡ المميزات المنفذة:
1. **🔍 فلتر وبحث سريع**: في شاشة التسجيل اليومي وشاشة الحسابات والعملاء للبحث الفوري عن أي زبون وسط الزحمة ومعرفة حسابه فوراً.
2. **👥 إضافة زباين بالجملة**: كتابة أسماء الزباين تحت بعض في صندوق النص، دون اشتراط تحديد أسعار مسبقة (الأسعار اختيارية).
3. **🔢 خانات إدخال فارغة تماماً**: لا يوجد رقم 0 مكتوب مسبقاً، الخانة فارغة وجاهزة للكتابة فوراً على لوحة مفاتيح الموبايل.
4. **🥛 أزرار الكسور باللغة العربية**: (+ ربع، + نص، + تلات أرباع، + كيلو، مسح).
5. **💬 إرسال الفاتورة عبر واتساب**: رسالة مفصلة بنقرة واحدة لكل زبون ببيانات كل يوم وإجمالي المبلغ المطلوب له.
6. **💾 حفظ تلقائي وأوفلاين (PWA)**: يعمل 100% بدون إنترنت مع إمكانية التثبيت على الهاتف وتصدير واسترجاع نسخة احتياطية (JSON) وتصدير Excel.
